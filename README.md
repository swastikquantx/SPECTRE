**SPECTRE - Autonomous MASTER AI AGENT**

SPECTRE uses every compatible free and open-source AI agent as a callable TOOL - not a dashboard that merely lists them.

```
UNDERSTAND → RESEARCH → PLAN → DISCOVER TOOLS → SELECT AGENTS → EXECUTE → OBSERVE → VALIDATE → REPAIR → DELIVER
```

## Architecture
- Common Adapter: capabilities, inputs/outputs, permissions, availability, health, timeout, retry, validation
- Dynamic Registry: Llama, HF, Ollama, LangGraph, CrewAI, AutoGen, smolagents, Playwright, Git, MCP
- Routing: 1) Local free 2) OSS hosted 3) Free-tier APIs 4) Paid only when explicitly enabled
- No fake outputs
